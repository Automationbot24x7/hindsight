Trust-weighted consensus

The loudest voice stops winning.

Every voice gets a trust score learned from its scored calls, with confident misses costing the most. The crowd view counts heads; Hindsight weighs them by track record, and flags when memory flips the crowd.

Portable, verifiable memory

Delete the database. Trust survives.

The local state is only a cache. Every trust score can be rebuilt from Walrus alone, and every memory is a blob on Sui mainnet that anyone can look up. A reflection step reads the memory back and writes new insights to it.
